# md-themes

柔和护眼的桌面 Markdown 编辑器主题合集。

## 目录结构

- `markflowy/`：适用于 [MarkFlowy](https://github.com/drl990114/MarkFlowy) 的声明式 JSON 主题（支持浅色 / 深色双模自动切换）
  - `everforest.json`：基于 [sainnhe/everforest](https://github.com/sainnhe/everforest) 的低饱和森林绿灰 / 燕麦米绿护眼配色
  - `solarized.json`：基于 [altercation/solarized](https://github.com/altercation/solarized) 的经典暖米色 / 深青灰对称对比度护眼配色
- `preview/`：全语法视觉预览与验收样本（`preview.md`）

## MarkFlowy 安装方法

1. 打开 MarkFlowy：**设置 → 外观 → 主题商店**。
2. 点击 **导入**，选择 `markflowy/` 目录下的 `.json` 主题文件。
3. 在本地主题中启用对应主题（如需让按钮与链接也使用主题强调色，可在 **设置 → 外观** 中将强调色切换为「跟随主题」）。
